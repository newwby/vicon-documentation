## <span class="toc-header">Creating a ProEclipse Database</span>

Navigate to the **Communications panel**, and the **data management tab** within (by default this panel is at the bottom of Vicon Nexus, the the data management tab is the default open tab).

![cs1_2_database_setup_1](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_1.png)
<span class="image-caption">Communications panel and data management tab</span>

Click the '**Show main ProEclipse menu**' button

![cs1_2_database_setup_1](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_1b.png)
<span class="image-caption">proEclipse menu button</span>

Click '**Manage eclipse databases**'.

![cs1_2_database_setup_2](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_2.png)
<span class="image-caption">Dropdown from clicking proEclipse menu button</span>

![cs1_2_database_setup_3](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_3.png)
<span class="image-caption">Eclipse database management window</span>

Use **'add new'** and select a destination directory - create new directory to keep information there

![cs1_2_database_setup_4](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_4.png)
<span class="image-caption">Adding a new database</span>

![cs1_2_database_setup_5](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_5.png)
<span class="image-caption">Exiting the database management window</span>

<span class="warning-text">Selecting the DB in this menu and closing the '<u>Manage Eclipse Databases</u>' window does not select the database!</span>

In order to do this you must click the '**show main ProEclipse menu**' button again and select the database

![cs1_2_database_setup_6](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_6.png)
<span class="image-caption">Selecting a database from the proEclipse dropdown</span>

Alternatively you can navigate to the database through the file explorer.

![cs1_2_database_setup_7](Public%20Files/Assets/capture_and_subjects/cs1_1_database_setup_walkthrough/cs1_2_database_setup_7.png)
<span class="image-caption">Selecting a database from the data management tab</span>

## <span class="toc-header">Creating a Subject Capture Session</span>
In order to use the database you need to set up a trial.

First you must create a new patient classification (a group for your subjects).

![cs1_2_subject_setup_1](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_1.png)
<span class="image-caption">New/empty database directory</span>

![cs1_2_subject_setup_2](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_2.png)
<span class="image-caption">Creating a classification group</span>

Click the button and name your group.

![cs1_2_subject_setup_3](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_3.png)
<span class="image-caption">Naming the classification group</span>

![cs1_2_subject_setup_4](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_4.png)
<span class="image-caption">A named classification group</span>

Double click the group to enter the directory. You'll see the button - previously '**create new patient classification**' has now changed.

Click the new button to create a new patient (subject) and name them.

![cs1_2_subject_setup_5](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_5.png)
<span class="image-caption">Creating a patient</span>

![cs1_2_subject_setup_6](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_6.png)
<span class="image-caption">Naming a patient</span>

![cs1_2_subject_setup_7](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_7.png)
<span class="image-caption">A named patient</span>

As before double-click to enter the directory - the available buttons will now change again.

Click the grey circle with the black segment to create a new capture session.

![cs1_2_subject_setup_8](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_8.png)
<span class="image-caption">Creating a capture session</span>

![cs1_2_subject_setup_9](Public%20Files/Assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_9.png)
<span class="image-caption">A named capture session</span>

If you open the **resources panel**, and switch to the **subjects tab,** you will now notice that the previously inactive (greyed-out) buttons are now able to be clicked.

<span class="info-text">This means your capture session is ready to start adding data.</span> You can now [create a labelling skeleton](Public%20Files/Documentation/2_2_skeleton_setup.md).
