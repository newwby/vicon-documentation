## <span class="toc-header">Creating a Subject Capture Session</span>

1. In order to use the database you need to set up a trial
2. First you must create a new patient classification (a group for your subjects)

![cs1_2_subject_setup_1](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_1.png)
![cs1_2_subject_setup_2](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_2.png)

17. Click the button and name your group

![cs1_2_subject_setup_3](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_3.png)
![cs1_2_subject_setup_4](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_4.png)

20. Double click the group to enter the directory.
21. You'll see the button - previously 'create new patient classification' has now changed.
22. Click the new button to create a new patient (subject) and name them.

![cs1_2_subject_setup_5](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_5.png)
![cs1_2_subject_setup_6](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_6.png)
![cs1_2_subject_setup_7](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_7.png)

26. As before double-click to enter that directory.
27. The available buttons will now change again.
28. Click the grey circle with the black segment to create a new capture session.

![cs1_2_subject_setup_8](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_8.png)
![cs1_2_subject_setup_9](Public%20Files/Vicon%20System%20Documentation/_assets/capture_and_subjects/cs1_1_db_subject_setup/cs1_2_subject_setup_9.png)

26. If you open the resources panel, and switch to the subjects tab, you will now notice that the previously inactive (greyed-out) buttons are now able to be clicked. This means your capture session is ready to start adding data.
