# Welcome!

This guide is written for the INB0104 fixed camera set-up at the University of Lincoln, using the specific software and hardware versions identified in the introduction. Whilst the guide is written to be as universal as possible, aspects will be tailored to the specific needs of that laboratory and may not be suitable for field configurations or other environments.

# Getting Started

The Vicon Nexus system for motion capture allows data collection and modelling from movements within a specific capture space (*the volume*).

The following documentation is designed as a quick-start guide to assist you with operating the system from no prior understanding. This is not an exhaustive guide to the functionality of the system as your use-case may vary from others.
