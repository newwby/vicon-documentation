# <span class="toc-header">STYLE GUIDE</span>
<span class="warning-text">You will need to remove this section if copying this page</span>

| Item                  | Rule                                                                                                                                                                                                                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Headers**           | <small>Main page title is h1, topics are h2, subtopics are h3.<br>Two line dividers should be used between h1 headers, and one line divider used between any h2 headers. No line dividers should be used between h3 headers.<br>All headers should use the <span class="toc-header">"toc-header"</span> css class. |
| **Images**            | <small>Images live in the <i>_assets/</i> directory, and use the <span class="image-caption">"image-caption"</span> css class for caption text beneath the image.                                                                                                                                                  |
| **Important Text**    | <small>Any sentences of importance should use the <span class="info-text">"info-text"</span> css class.                                                                                                                                                                                                            |
| **Critical Text**     | <small>Any sentences of importance should use the <span class="warning-text">"warning-text"</span> css class.                                                                                                                                                                                                      |
| **Lab Specific**      | <small>Information that relates specifically to the INB0104 lab setup should use the same rules as important text, but be preceded by <span class="info-text">'INB0104 Only:'</span>                                                                                                                               |
| **Panels**            | <small>Panel references (e.g. 'Tools', 'View', 'Resources') should be <b>bolded</b>.                                                                                                                                                                                                                               |
| **Tabs/Displays**     | <small>Tabs or displays referenced (categories within a panel, e.g. 'System Prepartion', '3D Perspective', 'Data Management', 'Properties'), should be <b>bolded</b> and in Title Case.                                                                                                                            |
| **Sections**          | <small>Sections within tabs/displays (e.g. 'Mask Cameras', 'Subject Calibration', 'Centroid Fitting', 'Processing History') should be <b>bolded</b> and in Title Case.                                                                                                                                             |
| **YAML Properties**   | <small>Each guide should utilise the YAML properties template at the top of this page template, allowing Obsidian to categorise the pages.                                                                                                                                                                         |
| **Table of Contents** | <small>Every guide should start with a table of contents, enclosed within two line dividers.<br>In Obsidian the 'Automatic Table of Contents' plugin can generate this.                                                                                                                                            |
| **Introduction**      | <small>Every guide should start with an <span class="toc-header">Introduction</span> header and a bullet-pointed list of what the guide covers.                                                                                                                                                                    |
| **Quick-Start Guide** | <small>Each guide collection should include a quick-start guide for users that wish to just get to the most pertinent information. This should ideally be a maximum of 3 guides.                                                                                                                                   |
