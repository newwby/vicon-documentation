# Welcome!

This guide will take you through how to use the Vicon Nexus 2.18 software.

Consider this guide a companion or reference guide for other guides within this documentation. If you find yourself struggling to find where something is located, check back to this guide.

To get started, begin with the **<span class="info-header">Vicon Nexus 2.18 Software Quick-Start</span>** guide below. This will take you through the need-to-know about the software, as a broad overview of where to find things within the program. How to use these features is the subject of other sections within the documentation.

Once you feel comfortable, move on to other sections within the documentation that match your usage needs. These are listed below in the order with which they

1. ***System Setup and Camera Functionality***
2. [Nexus System Preparation](Public%20Files/Vicon%20System%20Documentation/system_preparation/index%20(system_preparation).md)
3. ***Subject Capture and Data Pipelines***

If you wish to understand the software in full, you can check out the [full guide](#System%20Preparation%20Guide) below.
